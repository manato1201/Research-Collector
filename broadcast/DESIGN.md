### 3.1 コントラストの基準と実測(2026-11-11)

基準: 通常の文字 4.5:1 以上(WCAG 2.x AA)。**文字に使うトークンは、3 つの背景(`--bg`・`--surface`・`--surface2`)のどれの上でも 4.5:1 以上**にする、をトークンの段階で保証する。全組み合わせを計算した。

**測定で見つかり、直したもの**(旧 → 新。最悪の背景 `--surface2` での値)

## 4. 動き

1. **既存の動きは、それぞれの時間を持つ**。書き換えない。**これから足す動き**は、`style.css` のトークンを使う: `--dur-instant` 120ms・`--dur-open` 240ms・`--dur-enter` 300ms、`--ease-out` / `--ease-in` / `--ease-move`。動かす性質は `transform` と `opacity`。
2. **動きを減らす**: `prefers-reduced-motion: reduce` で、既存の動き(フェード・スケルトン・ティッカー・放送中の波形・図の線)がすべて止まる(JS の動きは `reduceMotion` を見る)。
3. 無限ループは 3 つだけ: `shimmer`(読み込み中)・`ticker-scroll`(ティッカー。reduce では折り返して静止表示)・`eq-bounce`(放送中の波形。状態に連動)。**新しい無限ループは足さない**。
4. **ちいさな遊び(2026-11)**: 触れたとき・切り替えたとき・現れたときの「**1 回きり**」の動きだけを足した(`style.css` の「アイコンと、ちいさな遊び」)。ナビ・ボタンのアイコンが触れると首をかしげる(`ico-wiggle`)・テーマの太陽 ⇄ 月が回って入れ替わる(`ico-spin`)・成功のトーストのチェックが書かれる(`ico-draw`)・空の状態の「放送の印」の弧が内側から順に現れる(`ico-fade`)。**無限ループは足していない**(`test/icons.test.js` が、この節に `infinite` が無いことと、動きが `no-preference` の中にだけあることを守る)。
5. **例外**: `eq-bounce` は `height` を動かす(規則は transform と opacity)。小さな 1 か所の表示なので残してある。触るときは `transform: scaleY` に寄せる。

## 5. アイコン

- **マーク**: 紫の角丸の正方形に、白い点と放送の弧 2 本(`public/favicon.svg`)。
- **一式(すでにある)**: `favicon.svg`・`apple-touch-icon.png`・`icon-192.png`・`icon-512.png`・`manifest.webmanifest`(PWA)。サイト固有の変更はしていない。
- **画面のアイコン(2026-11)**: `public/icons.js` に、線のアイコン一式(24×24・線の太さ 1.8・角と端は丸く・`currentColor`)。**放送の印(点 + 弧 2 本)を、全体の言葉にする**(ナビの「放送」・空の状態の図)。**文字は消さず、横に添える**(名前は文字が持つ。色や形だけに頼らない)。幅 560px 以下では、ナビは文字を読み上げ専用にして、アイコンだけを見せる。固定の HTML は `data-icon="名前"` で指定し、`decorate()` が足す。JS が作る表示は `icon("名前")` / `setLabel(要素, "名前", "文字")`。`test/icons.test.js` が、名前が実在することを守る。
