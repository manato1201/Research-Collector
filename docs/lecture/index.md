# Research-Collector 講義(基礎から)

技術情報の自動収集システムの**核の考え方・アルゴリズム**を、順に学ぶ講義です(標準ライブラリだけで動く部分)。各回は「**ゴール → 説明と実行できる例 → 確認問題 → 解答 → まとめ**」です。

| 回 | 題 | 学ぶこと | 目安 |
|---|---|---|---|
| [0](00-introduction.md) | 全体の見取り図 | 収集 → 重複 → 分類 → レポート・**重複は 2 段**・分類は補助 | 1 h |
| [1](01-semantic-dedup.md) | 意味の重複 | **2-gram + コサイン類似度**・数字の一致・しきい値・代表の優先順 | 3 h |
| [2](02-classifier.md) | 分類の補助 | キーワードの重み・単語境界・「どれでもない」・確信度 | 2.5 h |

例は、リポジトリのルートで動かします(ネットワーク不要)。講義のあとは [学習資料](../learn/index.md)。
