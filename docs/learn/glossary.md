# 用語集

| 用語 | 意味 |
|---|---|
| **コレクター(collector)** | ソースごとの収集関数(`collectors/`) |
| **ソース(source_type / platform)** | 記事の出どころ。`platform` は代表を選ぶ優先順に、`source_type` は追加先の決定に使う |
| **seen_urls** | 収集済みの URL のハッシュ(SHA-256 の先頭 16 文字)の一覧 |
| **意味の重複(semantic dedup)** | 別の URL の同じ話題を、タイトルの類似度で 1 つにまとめる |
| **2-gram** | 隣り合う 2 文字。日本語を単語に切らずに特徴にする |
| **コサイン類似度** | 2 つのベクトルの向きの近さ(0〜1) |
| **しきい値** | これ以上なら「同じ話題」とみなす値(既定 0.95) |
| **代表(keep)** | 同じ話題のうち、残す 1 本。公式 > 論文 > 個人記事 |
| **分類の補助(classifier)** | 3 カテゴリ + 「どれでもない」。実際の振り分けは、ソースの種類 |
| **none(どれでもない)** | 手がかりが無い。人の確認に回す |
| **確信度** | 最高点 ÷ 全カテゴリの得点の合計。同点なら下げる |
| **NotebookLM** | Google のノート型の AI。週次のノートブックに記事を追加する |
| **週次ノートブック** | カテゴリ × ISO 週で作るノートブック |
| **ダイジェスト** | 週ごとのまとめレポート(NotebookLM が生成) |
| **エピソード** | 日次・週次の記録のまとまり(`episodes.py`) |
| **ResearchBroadcast** | Cloudflare 上の別システム。収集した記事を送る(任意) |
| **health.json** | 実行の健康状態。README の表にも反映 |
| **HEALTH マーカー** | README の `HEALTH_START` 〜 `HEALTH_END`。bot がこの間を書き換える |
| **GitHub Actions / cron** | 定期実行。`0 9,21 * * *`(UTC)= JST 6:00・18:00 |
| **Secrets** | Actions の秘密の設定(`NOTEBOOKLM_AUTH_JSON` ほか) |
| **non-fast-forward** | リモートが先に進んでいて、そのままでは push できない状態 |
| **ISO 週** | 年の第何週か(月曜始まり)。`2026-W46` |
