// 01 · Overview

何を解決するシステムか

技術トレンドの変化が速く、分散した情報源を手動でキャッチアップするには限界がある。本システムは収集・整理・蓄積を完全自動化し、NotebookLMをAI外部脳として活用することでトークン消費ゼロで大量の技術資料を検索・活用できる環境を実現する。

1日2回の自動収集
RSS経由でZenn・Qiita・Unity/UE・CEDECと各種変更履歴の新着を、毎朝・毎夕6時に自動収集
論文収集
arXiv・Semantic ScholarからRAG/LLM/DCC学習関連論文を週2回(月・木)収集
重複チェック
URLのSHA256ハッシュに加え、タイトルの類似度でも判定。同じ話題の記事は代表1本に統合。収集済みはGitで永続化
週次ノートブック
カテゴリ別に週次ノートブックを自動作成。300件上限を超えない設計
分類と要確認
記事を3カテゴリに自動分類。どれにも当てはまらないものは「未分類」として人の確認に回す
レポート生成
収集内容からカテゴリ別の日本語まとめレポートを、水曜・日曜にNotebookLM CLIで自動生成
認証の維持
15分おきのセッション更新(GitHub Actions)と、1日2回の保険のログイン(Windowsタスクスケジューラ)
収集結果ビュー
集まった記事を期間・カテゴリで絞り込める一覧を、収集のたびに静的HTMLとして自動生成
// 02 · Architecture

システム全体の構成

3層構成：Windows タスクスケジューラ（認証） → GitHub Actions（収集） → NotebookLM（蓄積）
