# X(旧Twitter)の取り込み対象 — ここに書いた投稿URLだけが収集されます。
#
#  - 1行に1URL。`#` 以降はコメント、空行は無視されます。
#  - 書式: https://x.com/<ユーザー名>/status/<投稿ID>
#  - 検索・タイムライン巡回・フォロー先の自動取得は行いません(S4の方針)。
#  - 取得はサードパーティの中継サービス(fxtwitter)経由です。取得できなかった投稿は
#    静かにスキップされ、次回の実行で自動的に再試行されます(health.json に記録)。
#  - 取り込み済みの投稿は seen_urls.txt で管理されるため、行を消す必要はありません。
#
# 例(行頭の # を外すと有効になります):
# https://x.com/example_user/status/1234567890123456789
